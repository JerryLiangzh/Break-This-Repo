# Contributing to Break This Repository

Thank you for helping us break this repository in creative and educational ways.

## How to Contribute

1. Fork the repository.
2. Create a new branch for your experiment.
3. Make one focused and understandable change.
4. Explain what your change breaks.
5. Open a pull request.

## Good Contributions

Examples include:

- Funny or unexpected README content below the protected line.
- Broken links and intentionally incorrect documentation.
- Cross-platform filename experiments.
- Harmless API failures.
- Git and Markdown rendering experiments.
- Images, diagrams, jokes, and fictional release announcements.

## Protected Content

Do not modify:

- Anything inside `.github/`.
- Anything above the WARNING boundary in `README.md`.

## Keep the Damage Inside the Repository

Do not submit:

- Credential-stealing code.
- Malware or cryptominers.
- Destructive system commands.
- Code that attacks external websites or services.
- Real secrets or personal information.
- Content intended to harm another contributor's computer.

## Pull Request Checklist

Before submitting, confirm that:

- [ ] I did not modify `.github/`.
- [ ] I did not modify the protected README section.
- [ ] My change is confined to this repository.
- [ ] My PR explains the intended visible effect.
- [ ] My change does not harm users or third-party systems.

Have fun and break responsibly.
